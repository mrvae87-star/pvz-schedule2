## 🚀 Возможности

- 📅 **График работы** - визуальный календарь с отметками рабочих дней
- 👥 **Управление сотрудниками** - добавление, редактирование, удаление
- 🏪 **Управление ПВЗ** - создание и настройка пунктов выдачи
- 💰 **Расчёт зарплаты** - автоматический подсчёт с учётом ставок и подработок
- 📊 **Аналитика** - просмотр графиков работы сотрудников
- 💬 **Внутренний чат** - обмен сообщениями с вложениями
- 🆘 **Экстренные контакты** - хранение контактов сотрудников
- 📄 **Документы** - загрузка и просмотр документов

## 🛠️ Технологии

- **Frontend**: Vanilla JavaScript (ES Modules)
- **База данных**: Firebase Firestore
- **Стили**: CSS3
- **Сборка**: Нет (работает напрямую в браузере)
